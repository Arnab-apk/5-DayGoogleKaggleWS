## 🧠 Overview

This repository contains all materials, notebooks, and exercises from the **Google Kaggle AI Agents Intensive Course** — a 5-day journey designed to help learners understand, build, and deploy intelligent **autonomous AI agents** using the latest **Model Context Protocol (MCP)** and **Agent2Agent (A2A)** standards.

By the end of this course, you’ll have the skills to:
- Design and implement your own AI agent systems  
- Integrate external tools and APIs via **MCP**  
- Engineer memory and context for **multi-turn conversations**  
- Evaluate and improve **agent performance**  
- Deploy scalable **production-ready multi-agent systems**

---

## 📅 Course Breakdown

| Day | Topic | Description |
|-----|--------|-------------|
| **Day 1** | 🧩 *Introduction to Agents* | Explore the foundational concepts of AI agents, their defining characteristics, and how agentic architectures differ from traditional LLM apps. Lay the groundwork for building intelligent, autonomous systems. |
| **Day 2** | 🛠️ *Agent Tools & Interoperability with MCP* | Learn how AI agents “take action” by leveraging external tools and APIs. Discover the ease of connecting and managing functionalities via the **Model Context Protocol (MCP)**. |
| **Day 3** | 🧠 *Context Engineering: Sessions & Memory* | Build agents that can remember and use past interactions. Learn to implement short-term and long-term memory for robust multi-turn tasks and complex workflows. |
| **Day 4** | 🧾 *Agent Quality* | Learn to evaluate, test, and refine your agents. Master observability, logging, and performance metrics to optimize agent behavior and reliability. |
| **Day 5** | 🚀 *Prototype to Production* | Take your local prototype global. Learn best practices for deploying AI agents at scale, creating interoperable systems using the **Agent2Agent (A2A)** protocol. |
